🔗 Data Flow Between Roles
From To Data / Action Trigger
🛡️ Admin → 📺 Monitor 🎤 Host ⚖️ Judge Event created, participants added, stage opened Admin creates/activates event
🛡️ Admin → ⚖️ Judge Scoring criteria, subject weights, judge assignment Admin assigns judge to event
🎤 Host → 📺 Monitor ⚖️ Judge Participant pushed to stage, stage status update Host clicks "Push to Stage"
⚖️ Judge → 🛡️ Admin 📺 Monitor Scores submitted and locked per participant Judge locks score
📺 Monitor → 🌐 Public Live rankings broadcast, result published flag Monitor toggles "Result Public"
📺 Monitor → ⚖️ Judge Judge credentials created, agreement confirmed Monitor completes judge agreement form
🌐 Public → 🛡️ Admin Public registration form submitted Audience registers for event
📺 Monitor → 🛡️ Admin 🎤 Host ⚖️ Judge 🚨 SOS Alert broadcast to all staff Monitor sends SOS
